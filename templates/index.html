Scanner Features

Security Headers

Checks configured HTTP security headers and identifies missing or invalid values.

Cookie Security

Checks cookie attributes such as Secure, HttpOnly and SameSite.

Technology Detection

Identifies server technology information disclosed through HTTP response headers.

Scan History

Saves scan results in the database so you can review previous scans and their findings.

Severity Classification

Organizes findings by severity to help prioritize security review.

OWASP Mapping

Provides contextual security descriptions and references for supported findings.

Important Notice

Use this scanner only on systems you own or have explicit permission to test. Findings are indicators that require manual verification; they are not automatically confirmed vulnerabilities.
